## 🤖 Generative AI Practice (GenAI)

This folder contains my hands-on practice and experiments with **Generative AI**, focusing on real-world use cases and modern AI development workflows.

### 🔹 What’s included
- LLM-based applications using **OpenAI** and **Hugging Face**
- **LangChain** implementations (chains, prompts, agents, tools)
- **RAG (Retrieval-Augmented Generation)** pipelines
- Prompt engineering experiments
- AI agents with tool calling
- Jupyter notebooks and Python scripts for learning and experimentation

### 🔹 Key Concepts Covered
- Large Language Models (LLMs)
- Prompt Engineering
- Vector Databases & Retrievers
- Embeddings
- Agents & Tool Calling
- Environment-based API key management

### 🔐 Security Note
API keys (OpenAI, Hugging Face, etc.) are **not included** in this repository.  
All sensitive credentials are loaded securely using environment variables (`.env` files), which are ignored via `.gitignore`.

### 🛠 Tech Stack
- Python
- LangChain
- OpenAI API
- Hugging Face Transformers
- FAISS / Vector Stores
- Jupyter Notebook

> ⚠️ This folder is meant for **learning, experimentation, and skill demonstration**, not production deployment.
